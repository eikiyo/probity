# Security Policy

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, use one of:
- GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) (Security tab → "Report a vulnerability"), or
- email **syedmosayebalam@gmail.com**.

Include: a description, steps to reproduce, affected version(s), and impact. We aim to acknowledge within **48 hours** and provide a fix or timeline within **7 days**.

## Supported versions

| Version | Supported |
|---------|-----------|
| latest  | ✅        |

## Disclosure

We follow coordinated disclosure: we'll work with you on a fix and credit you (if you wish) in the release notes once a patch is available.
